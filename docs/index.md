# raclib

Библиотека на языке Python для работы с **сервером администрирования 1С:Предприятия**
через утилиту `rac`. Она не обращается к серверу по сети напрямую: `rac`
запускается как подпроцесс, а его текстовый вывод разбирается в словари Python.

[Примеры](guides/recipes.md){ .md-button }
[Справочник API](reference/index.md){ .md-button }

## Что умеет

- **Все команды кластера** — кластеры, рабочие серверы, информационные базы,
  сеансы, соединения, блокировки, счётчики производительности, ограничения
  ресурсов, требования размещения, профили безопасности.
- **Синхронный и асинхронный интерфейсы** — `Client`/`Session` и
  `AsyncClient`/`AsyncSession` с одинаковым набором методов.
- **Разбор вывода RAC** в словари или `dataclass`.
- **Понятные исключения** вместо текста из `stderr`.
- **Настраиваемая кодировка** вывода и **таймаут** запуска `rac`.

Внешних зависимостей нет, требуется Python 3.12+.

## Тридцать секунд

```python
import raclib as rc

client = rc.Client("/opt/1cv8/x86_64/8.3.24.1548/rac")
session = rc.Session(client, timeout=30)

for cluster in rc.Cluster.list(session):
    print(cluster["cluster"], cluster["name"])
```

## Как это работает

```text
ваш код
   │  rc.Cluster.list(session)
   ▼
raclib.Session            формирует argv: rac host:port cluster list
   │  subprocess / asyncio
   ▼
rac  (утилита из поставки сервера 1С)
   │  текстовый вывод «ключ : значение»
   ▼
raclib.RawOutput          разбирает в dict / list[dict] / dataclass
```

Логика разбора вывода и таблица ошибок общие для обеих веток
(`raclib/_shared.py`), а асинхронные команды генерируются из синхронных —
подробности в разделе [Разработка](contributing.md).
